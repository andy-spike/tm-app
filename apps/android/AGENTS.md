# Native Android app

Kotlin 2.4, Jetpack Compose (Material 3), Navigation 3, Hilt, Room, DataStore, MapLibre 13. AGP 9.5 with Gradle 9.9 via the wrapper. JDK 21. See [the plan](../../docs/android/PLAN.md) for scope and defaults.

## Modules

| Module | Contents |
| --- | --- |
| `core/transit` | Pure Kotlin/JVM: TMBG decoder, RAPTOR router, departures, search, route codes, shapes. No Android imports. |
| `core/data` | Bundle store and Cloudflare sync, `TransitRepository`, Room, DataStore, location. |
| `app` | Compose UI, navigation, theme, map wrapper, Hilt graph, WorkManager sync. |
| `baselineprofile` | Baseline profile generator and startup benchmark. |

## Rules

- Keep `core/transit` platform-free and allocation-light: flat primitive arrays, no per-trip objects. Phones give apps ~192 MB of heap; the decoded timetable must stay well under that.
- All schedule maths uses `BOGOTA` (America/Bogota). Never use the device time zone for service days.
- Every time shown must say it is scheduled (`ScheduledTag`, `Horario programado`). Never present v1 data as live.
- UI text lives in `res/values/strings.xml` (Spanish source) and `res/values-en/strings.xml`. Add both.
- Tappable targets are at least 48 dp. Rows with a custom spoken label use `clearAndSetSemantics`.
- `minSdk` is 28. Lint fails on newer APIs (for example `LocalTime.ofInstant`); the JVM module is not linted, so keep to Java 8 time APIs there.
- The map is decorative for accessibility; every map has an equivalent list.

## Data

The APK bundles the pipeline's latest output (`timetable.bin`, `shapes.json`, `bogota.pmtiles`) through the `syncBundle` Gradle task. Run `pnpm bundle:maps` and `pnpm bundle:build` first. Checks pass `-Ptm.allowMissingBundle=true` so fresh worktrees can lint without data. Map styles and glyphs are generated by `pnpm --filter @tm/pipeline map-style` and committed under `app/src/main/assets/map`.

Debug builds talk to this checkout's Worker at `http://localhost:<bundle port>`; override with `-Ptm.apiBaseUrl=…`.

## Run on the assigned emulator

```bash
pnpm api                                  # Cloudflare Worker on this checkout's bundle port
pnpm api:publish                          # upload the latest bundle to local R2/D1
cd apps/android && ./gradlew :app:assembleDebug
adb -s <serial> install -r app/build/outputs/apk/debug/app-debug.apk
adb -s <serial> reverse tcp:<bundle port> tcp:<bundle port>
```

Launch `com.tmapp.android` with the device-bound `agent-device` command. Validate with `pnpm android:check` (transit tests and Android lint), included in `pnpm check`.
